# Changelog

Todos los cambios importantes de PyPozo se documentan en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
y este proyecto sigue [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Sin versión] - 2025-08-22

### Mejorado
- README.md completamente reescrito y simplificado
- Documentación organizada y estructurada
- pyproject.toml mejorado con mejor descripción y keywords
- URLs del proyecto corregidas

### Corregido  
- Documentación redundante y desorganizada eliminada
- Estructura de archivos documentada correctamente

## [2.0.0] - 2025-07-02

### Añadido
- Interfaz gráfica profesional con PyQt5
- Sistema de fusión automática de pozos
- Cálculos petrofísicos avanzados (VCL, Porosidad)
- Análisis litológico automático  
- Sistema de logging completo
- Soporte para múltiples formatos de exportación

### Mejorado
- Arquitectura modular y extensible
- Visualización científica avanzada
- Documentación técnica completa

### Cambiado
- Migración completa desde arquitectura monolítica
- Nuevas APIs y métodos de uso

## [1.x] - Versiones anteriores

### Características Iniciales
- Análisis básico de pozos
- Procesamiento de archivos LAS
- Cálculos petrofísicos fundamentales
